Аналитика сайта

Дата обновления: 25 октября 2026 года.

На сайте игры «Рубеж» используется Google Analytics 4, чтобы оценивать посещаемость, источники переходов, типы устройств и нажатия на кнопки скачивания Android и Windows.

Аналитика включается после выбора «Разрешить аналитику». Google получает технические сведения о посещении сайта и взаимодействиях с ним; для различения посещений используются файлы cookie. Персонализация рекламы и Google Signals отключены. Игровой профиль, переписка, валюты и сведения об оплате в аналитику сайта не передаются.

Ваш выбор сохраняется в браузере. Отказ от аналитики не мешает скачиванию игры. Изменить выбор можно кнопкой ниже или ссылкой «Настройки аналитики» внизу главной страницы.

Подробнее об обработке данных Google: политика конфиденциальности.

Счётчики скачиваний

Публичные счётчики показывают суммарное количество загрузок файлов игры из GitHub Releases за все опубликованные версии. Они учитывают обновления и повторные загрузки и не равны числу уникальных игроков. Для обновления значений браузер обращается к публичному API GitHub; последний результат может сохраняться локально на один час.
